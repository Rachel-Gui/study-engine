  This is a real terminal: a text window where you type commands. On Windows it is
  PowerShell or the terminal app; on a Mac, Terminal. The text before the cursor is the
  prompt, and it tells you which folder you are in. Type c d data, and the prompt changes:
  you are now inside the data folder. Dir lists what is there, one file. C d dot dot
  goes back up, and dir shows the folder again. The mistake everyone makes is running a
  command from the wrong folder. A terminal opened from the start menu starts in your
  home folder, not your project, so c d into the right one first.
:::

:::scene{type=cards}
heading: Four terminal commands you will use constantly
items:
  - title: cd folder
    text: change into a folder. cd Documents
    tag: move
  - title: cd ..
    text: go up one level, back to the parent folder
    tag: move
  - title: dir  /  ls
    text: list what is here. dir on Windows, ls on a Mac
    tag: look
  - title: Ctrl + C
    text: stop whatever is running. Works everywhere.
    tag: stop
narration: |
  Four commands cover almost everything. C D and a folder name moves into that folder.
  C D dot dot goes up one level. Dir on Windows, or L S on a Mac, lists what is here.
  And control C stops whatever is running. If a command says no such file, you are in
  the wrong folder; C D fixes it.
:::

:::scene{type=quiz}
question: You installed Python on Windows, went back to a terminal that was already open before the install, and typed python. It says "not recognized". What is the most likely cause?
options:
  - Python installed incorrectly and you need to reinstall it
  - The terminal was open before the install, so it does not know Python exists yet
  - Windows needs a restart before any new program works
answer: 1

explain: A terminal reads the list of programs when it opens. Close it, open a new one, and try again. If it still fails, run py install --refresh (install manager) or reinstall with the PATH box ticked (standalone installer).
narration: |
  A quick check. You installed Python on Windows, went back to a terminal that was
  already open, and typed python. It says not recognized. What is the most likely cause?
  A: the install went wrong. B: the terminal was open before the install, so it does not
  know Python exists yet. C: Windows needs a restart. Pause and pick one.
after: |
  It is B. A terminal reads the list of available programs when it opens. Close it, open
  a new one, and try again. If it still fails, PATH is the problem: with the install
  manager, run p y install dash dash refresh; with the standalone installer, run it again
  and tick the PATH box. This one mistake causes more first day frustration than
  everything else combined.
:::
