:::scene{type=screen kind=terminal}
heading: The terminal — and the mistake everyone makes
text: A text window. The prompt shows the folder you are in; you type a command after it and read the answer underneath. Commands only work from the right folder.
title: Command Prompt
prompt: "C:\\Users\\you>"
lines:
  - "$ python --version"
  - "Python 3.13.2"
  - "$ cd Documents\\ai-course"
  - "$ dir"
  - " hello.py    data    notebooks"
callout: The prompt is the folder you are in
narration: |
  This is the terminal: a text window where you type commands. On Windows it is called
  Command Prompt or PowerShell; on a Mac, Terminal. The text before the cursor is the
  prompt, and it tells you which folder you are in. Type python space dash dash
  version, press enter, and Python answers with its version number. That is how you
  know step one worked. Then the mistake everyone makes: a terminal opened from the
  start menu starts in your home folder, not your project. C D and the folder name
  moves you into the right one, and dir, or L S on a Mac, lists what is there.
:::

:::scene{type=cards}
heading: Four terminal commands you will use constantly
items:
  - title: cd folder
    text: change into a folder. cd Documents
    tag: move
  - title: cd ..
    text: go up one level, back to the parent folder
    tag: move
  - title: dir  /  ls
    text: list what is here. dir on Windows, ls on a Mac
    tag: look
  - title: Ctrl + C
    text: stop whatever is running. Works everywhere.
    tag: stop
narration: |
  Four commands cover almost everything. C D and a folder name moves into that folder.
  C D dot dot goes up one level. Dir on Windows, or L S on a Mac, lists what is here.
  And control C stops whatever is running. If a command says no such file, you are in
  the wrong folder; C D fixes it.
:::

:::scene{type=quiz}

  - Python installed incorrectly and you need to reinstall it
  - The terminal was open before the install, so it does not know Python exists yet
  - Windows needs a restart before any new program works

narration: |
  A quick check. You installed Python on Windows, went back to a terminal that was
  already open, and typed python. It says not recognized. What is the most likely cause?
  A: the install went wrong. B: the terminal was open before the install, so it does not
  know Python exists yet. C: Windows needs a restart. Pause and pick one.
after: |
  It is B. A terminal reads the list of available programs when it opens. Close it, open
