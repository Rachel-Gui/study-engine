:::scene{type=idea icon=warn}
text: A p-value answers one narrow question.
sub: Could a difference this large appear by chance if there were none? It does not say the difference matters, and it does not say what caused it.
narration: |
  A p value answers one narrow question: could a difference this large appear by
  chance if there were really no difference? That is all. It does not say the
  difference matters. It does not say what caused it. And with seven hundred and sixty
  eight rows, even tiny differences get small p values. Module six replaces this
  question with a better one: does the pattern hold on data the model has never seen?
:::

:::scene{type=cards}
heading: What this dataset spared you — the gaps, and why they matter
items:
  - title: Missing at random
    text: The gaps depend on nothing. Drop or impute; you lose precision, not truth.
    tag: MCAR
  - title: Missing given what you can see
    text: The meter fails in one building type. Model the missingness; impute conditionally.
    tag: MAR
  - title: Missing because of the value
    text: The highest loads are the ones unrecorded. No imputation fixes it — report the limit.
    tag: MNAR
  - title: Rare classes
    text: One class is most of the rows. Beat the majority-class baseline; precision–recall, not accuracy.
    tag: imbalance
narration: |
  This dataset has no missing values and its groups are all the same size, which is
  rare, and it hides two checks you will need on every real table. The first is
  missingness, and the question is not only how much is missing but why. If a sensor
  dropped readings at random, the rows you have are still a fair sample. If the gaps
  depend on something you can see, say the meter fails in one building type, you can
  model around it. But if the gaps depend on the missing value itself, say the highest
  loads are the ones that went unrecorded, then every mean you compute is biased, and
  no imputation can tell you by how much. The lesson page makes this happen to the
  dataset, so you can watch the mean move. The second check is imbalance. When one
  class dominates, accuracy is a trap: a model that always predicts the common class
  scores well and is useless. Lesson six point four shows what to report instead.
:::
