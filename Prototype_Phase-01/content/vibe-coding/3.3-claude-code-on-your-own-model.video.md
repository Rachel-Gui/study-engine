:::scene{type=title}

  Welcome to lesson three point three, Claude Code on your own model. Claude Code is an
  agentic coding tool: a program in your terminal that reads your project, plans,
  edits files, runs commands, and asks you before anything risky. It normally uses a
  hosted model. In this lesson you point it at the free model already on your laptop,
  so it runs offline, costs nothing, and lets you watch an agent work step by step.

:::scene{type=code}
heading: The three settings — or one launcher
code: |
  # the quick way
  ollama launch claude

  # or by hand (macOS / Linux; PowerShell uses $env:NAME = "...")
  export ANTHROPIC_AUTH_TOKEN=ollama
  export ANTHROPIC_API_KEY=""
  export ANTHROPIC_BASE_URL=http://localhost:11434
  claude --model qwen3
note: The settings last for that terminal window only. Close it and Claude Code goes back to normal. If it asks you to log in, the settings did not reach it — set them again in the same window you start claude from.
narration: |
  The quickest way is Ollama's own launcher: ollama launch claude, which sets
  everything for you. Or set three environment variables yourself: an auth token that
  just says ollama, an empty A P I key, and the base U R L of your local server. Then
  start claude with the model name. The settings last for that terminal window only,
  which is what you want. If Claude Code asks you to log in, the settings did not reach
  it: set them again in the same window you start it from.
:::

  Make a small folder with one Python file in it, the bar building rule from lesson
  three point two is ideal, open a terminal inside it, and start Claude Code. Ask for
  something bounded: add a docstring to every function and explain what you changed.
  Then watch. It reads the files: observe. It says what it intends: plan. It shows the
  edit and waits: the human gate. It applies the edit and reports: act and check. Its
  own check is not a substitute for yours.
:::

:::scene{type=idea icon=warn}
text: A local model is a weaker coding agent. / That is the point.
sub: Slower, more mistakes, in need of a sharper brief. For real work, use a hosted model. For understanding the loop, the local one is ideal — every step is visible and it costs nothing.
narration: |
  Set your expectations. A local eight billion parameter model is a much weaker coding
  agent than a hosted frontier model: slower, more mistakes, in need of a sharper brief.
  That is not a bug; it is the size of the model. For real work, a hosted model is the
  better tool. For understanding how an agent loop behaves, the local one is ideal,
  because every step is visible and it costs nothing.
:::
