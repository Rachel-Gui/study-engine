:::scene{type=steps}
heading: The eleven steps, in three groups
steps:
  - Python, VS Code, Ollama — you may already have them
  - The Negotiators folder — unzip, then open a terminal inside negotiators
  - llama3.1 — pull it, and point one line of code at it
  - Python packages and Node.js — pip, then npm
  - "*verify.py — nine or ten green plus signs"
  - Run both servers — backend, then frontend
narration: |
  Three groups. First, the tools: Python, VS Code and Ollama, which you may already
  have. Second, the Negotiators folder: unzip it, and open a terminal inside the
  negotiators folder, which is the step everyone gets wrong. Third, the model: pull
  llama three point one and change one line of code so the code knows which model
  to use. Then the packages: pip for Python, n p m for the dashboard, and a fresh
  terminal after installing Node. Then verify: a script that checks everything and
  prints nine or ten green plus signs. And finally, run both servers.
:::

:::scene{type=idea icon=warn}
text: Every command only works if the terminal / is inside the negotiators folder.
sub: A terminal opened from the Start menu or Spotlight starts in your home folder. Navigate into negotiators first, and keep that window open.
narration: |
  The step students mess up most, in one sentence. Every command in this setup only
  works if your terminal is currently sitting inside the negotiators folder. A terminal
  opened from the start menu or Spotlight starts in your home folder, and from there
  every command fails with no such file. The lesson page shows the two ways to open a
  terminal in the right place. Do that once, and keep the window open for the rest of
  the steps.
:::

:::scene{type=compare}

    - Reloads itself when you save the file
    - Leave it running

  title: Terminal 2 — frontend
  points:
    - npm run dev, inside the frontend folder
    - The dashboard page in your browser
    - Shows how many agents are online
    - Leave it running too
verdict: Confirm Ollama is running first — the llama icon in the tray or menu bar. The backend crashes on startup without it.
narration: |
  During the session you keep two terminals open. Terminal one runs the backend: it
  reads negotiators dot p y, calls Ollama, returns JSON, and reloads itself whenever you
  save the file. Terminal two runs the frontend, the dashboard in your browser, which
  shows how many agents are online. Leave both running. And before you start either,
  confirm Ollama is running: look for the llama icon in your tray or menu bar. The
  backend crashes on startup without it.
:::
