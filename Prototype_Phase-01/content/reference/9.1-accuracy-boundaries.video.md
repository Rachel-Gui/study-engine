:::scene{type=list}
heading: The boundaries — part one
items:
  - A neural network does not think like a human brain
  - Correlation is not causation
  - A p-value is not the probability a hypothesis is true, and not practical importance
  - High R² or accuracy is not, by itself, evidence of reliability
  - Deeper networks are not automatically more accurate
  - The test set is never used for tuning
narration: |
  Part one. A neural network does not literally think like a human brain. Correlation is
  not causation. A p value is not the probability that a hypothesis is true, and not a
  measure of practical importance. A high R squared or accuracy is not, by itself,
  evidence of reliability. Deeper networks are not automatically more accurate. And the
  test set is never used for tuning. You have met every one of these in a lesson. Here
  they are in one place.
:::

:::scene{type=list}
heading: The boundaries — part two
items:
  - Records from one building or simulation family never leak across the split
  - It is a GNN only when a neural message-passing model was used
  - Physics-informed ML, PINN, hybrid, surrogate and INR are not interchangeable
  - A fast surrogate does not always replace high-fidelity simulation
  - A realistic image is not evidence of constructability or performance
  - Always state the data range, geometry range, climate range, metrics, uncertainty and known failures
narration: |
  Part two. Records from one building or one simulation family never leak across the
  split. It is a graph neural network only when a neural message passing model was
  actually used. Physics informed learning, P I N N, hybrid model, surrogate and I N R
  are not interchangeable words. A fast surrogate does not always replace high fidelity
  simulation. A realistic image is not evidence of constructability or performance. And
  the one people skip most: always state the range. Data range, geometry range, climate
  range, metrics, uncertainty, known failure conditions. A number with no stated range is
  not a result.
:::

  How to use this page. As a checklist, before you write a script, a slide or a diagram,
