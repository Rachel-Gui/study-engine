## Central question

Can we predict a building's annual energy use from its physical, operational, and
environmental characteristics?

:::narration
Module two starts with the simplest useful thing you can do with data: draw a line
through it. Regression predicts a number on a continuous scale. Classification, which
is the next episode, predicts which category something belongs to. It sounds like a
small distinction and it changes everything downstream — the model, the loss
function, and every metric you report.
:::

## Regression versus classification

{{Regression}} predicts a number on a continuous scale. {{Classification}} predicts
which discrete category an example belongs to.

:::cards
Regression | Building features → 1,370,845 kWh | A continuous number. Use it unless the decision genuinely needs a documented performance band.
Classification | Building features → Low / Medium / High | A discrete category, chosen from a fixed set of labels.
:::

Regression is a supervised method that predicts a continuous numerical outcome by
learning relationships between that outcome and one or more input {{features}}.

:::cards
X | input features / predictors | building area, height, year built
Y (or y) | observed outcome / target | measured annual energy use
ŷ | model prediction | estimated annual energy use
:::

Training uses buildings where both X and Y are known. For an unseen building,
the model uses its features X to predict ŷ; the observed y is needed to check that
prediction. Lowercase x denotes one predictor value for one building.

## How linear regression works

For one predictor *x*, **ŷ = wx + w₀** gives the prediction, with slope *w* and
intercept *w₀*. The vertical gap is **residual = y − ŷ = observed − predicted**:
positive means underprediction; negative means overprediction.

:::widget{id=regression-line-lab}
:::

Drag a point, inspect its residual, then press **Refit** to minimise the sum of
squared residuals. Fitting these observations does not test performance on unseen
buildings.

:::narration
The filled point is an observed outcome. The open point on the line is the model's
prediction at the same input. The vertical gap is the residual: observed minus
predicted. Moving an observation changes its residual. Refitting changes the line
to minimise the sum of squared residuals across all observations. These points use
an illustrative scale, not measured campus energy data.
:::

## From simple to multiple regression

The previous topic used one predictor, x. Multiple regression uses several
predictors together in X, with one coefficient per predictor:

:::cards
Simple regression | Area → predicted energy use | One predictor, one slope
Multiple regression | Area + height + year built → predicted energy use | Parallel inputs, one coefficient per predictor
:::

**ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + w₀**

Each coefficient describes the model's fitted relationship with one feature *while
the other included features are held constant*. Changing the feature set can change
the coefficients. Their units differ, so a larger raw coefficient does not by
itself mean a more important predictor.

## Architectural example

:::cards
Geometric | area, height, building length | physical characteristics
Operational / program | year built, occupants, program | building use and operation
Environmental | tree canopy, land-surface temperature | surrounding conditions
:::

These groups supply predictors **in parallel**, not as consecutive processing steps.
Orientation and relative compactness are other possible geometric predictors.

:::flow
Selected features together (X) > Multiple linear regression > Predicted annual energy use (ŷ)
:::

The observed annual energy use Y is the training target, not an input available
when predicting an unknown outcome. Predictive relationships do not establish
that changing a building feature would cause its energy use to change.

## Model evaluation

:::cards
Residual | y − ŷ | signed vertical gap, per building
MAE | average of absolute residuals | in kWh for annual energy; signs cannot cancel. Lower is better
RMSE | root mean squared error | same units, punishes large misses harder
R² | share of variance explained | on the data it was evaluated on
:::

:::keyidea
A high R² does not by itself prove that the model is reliable, or that a feature
*causes* energy consumption to change. Check unseen-data error, residuals, data
quality, and domain plausibility.
:::

:::reflect
Your model's R² rises when you add a feature. What have you learned?
- The new feature causes energy use to change
- *That the fit improved on this data — which says nothing yet about unseen buildings
- That the model is now reliable enough to report
:::
