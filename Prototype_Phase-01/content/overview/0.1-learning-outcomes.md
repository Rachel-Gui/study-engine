## Purpose and audience

**Purpose** — detailed teaching content, demonstrations, and diagram prompts for
short instructional videos.

**Audience** — architecture and built-environment students with basic data literacy.

**Central question** — how can architectural data be transformed into evaluated
machine-learning models and, when appropriate, more specialized deep-learning systems
that support responsible design decisions?

:::narration
Welcome to modules two and three. The central question across both is this: how can
architectural data be turned into evaluated machine-learning models, and where
appropriate more specialised deep-learning systems, that support responsible design
decisions. Note the word evaluated, and note the word responsible. Getting a model to
produce a number is the easy part of this course. Knowing what that number is worth
is the rest of it.
:::

## By the end of Modules 2–3 you should be able to

- Distinguish supervised, unsupervised, semi-supervised, and reinforcement learning.
- Translate an architectural question into {{features}}, targets, data
  representations, and a suitable learning task.
- Explain the complete machine-learning workflow from preprocessing through
  deployment and monitoring.
- Build and evaluate {{regression}} and {{classification}} models using
  task-appropriate metrics.
- Explain feature selection, multicollinearity, {{generalization}},
  {{underfitting}}, {{overfitting}}, and {{cross-validation}}.
- Explain the structure and training process of an artificial neural network.
- Match MLPs, CNNs, sequence models, Transformers, {{GNN}}s, physics-informed models,
  and {{INR}}s to suitable architectural data.
- Evaluate technical accuracy, physical plausibility, domain transfer,
  {{uncertainty}}, and design usefulness.

## Core message

:::keyidea
Begin with the architectural question and the data. Select the simplest model that
can answer the question reliably, evaluate it on unseen data, and keep domain
knowledge and human judgment in the decision loop.
:::

:::flow
Architectural question > Data representation > Model > Evaluation > Design decision
:::

## Before the first lab

Three setup guides and a Python course follow this page. Every setup command has a
Windows and a macOS version, and every guide ends with a verification step. Do them in
order, before class, on the laptop you will bring.

:::cards
0.2 Setup 1 | Python, VS Code, the terminal, the course libraries, Google Colab | about 45 minutes
0.3–0.5 Python from zero | three chapters for students who have never written code: values, collections, loops, functions, classes, libraries, errors | skip if you already write Python
0.6 Exploratory data analysis | numpy, pandas, matplotlib, seaborn and scipy on a real dataset of 768 buildings, plus a page of resources | about 2 hours
0.7 Setup 2 | Ollama, a free local model, calling it from Python, Claude Code (optional) | about 40 minutes
0.8 Setup 3 | The Agentic AI workshop: the Environmental Negotiators stack, verified end to end | about an hour
:::

:::keyidea
**Colab for the notebooks, your laptop for the workshops.** The Module 2 and 3 labs on
this site run in the browser with nothing installed. The Module 4 workshop needs a
local model and two servers, which is what Setup 3 installs.
:::
