  The question for the lesson. How can a network of simple mathematical units learn a
  relationship between geometry, climate and performance that no formula captures? The
  answer has three parts, and they are the three parts of this video. One neuron is a

:::scene{type=diagram id=timeline}
heading: Where neural networks came from
points:
  - 1943 — the neuron as a logic unit
  - 1958 — the perceptron, which could only draw straight lines
  - 1986 — backpropagation, a way to train stacked layers
  - 2012 — data and GPUs, not new mathematics
narration: |
  A little history, because it explains something. The idea of a neuron as a unit of
  computation dates from nineteen forty three. The perceptron of nineteen fifty eight
  could learn, but only straight boundaries, and interest collapsed. Backpropagation in
  nineteen eighty six gave an efficient way to train a stack of layers. And then almost
  nothing changed mathematically until twenty twelve. What changed was data and graphics
  cards. Remember that when a network underperforms: the fix is usually more or better
  data, not a cleverer architecture.
:::

:::scene{type=diagram id=neuron}
heading: One artificial neuron
points:
  - Inputs x — temperature, humidity, hour
  - Weights w and a bias b — the numbers that are learned
  - z = w₁x₁ + w₂x₂ + w₃x₃ + b — a weighted sum
  - a = φ(z) — an activation, chosen by you
narration: |
  Here is one artificial neuron, and it is a function, not a brain cell. Inputs come in:
  say a temperature, a humidity and an hour of the day. Each input is multiplied by a
  weight. The products are added up, together with a bias. That gives z, the weighted
  sum. Then z goes through an activation function, phi, which gives the output. The
  weights and the bias are learned from data. The activation is chosen by you. That is
  the entire neuron.
:::

:::scene{type=code}
heading: The neuron, and then a tiny network, by hand
code: |
  def relu(z):                         # the switch: pass positives, block negatives
      return z if z > 0 else 0

  x  = [21.5, 44.0, 19.0]              # temperature, humidity, hour
  W1 = [[0.8, -0.2, 1.4],              # hidden neuron 1
        [-0.5, 0.1, 0.3]]              # hidden neuron 2
  b1 = [-3.0, 2.0]

  z1 = 0.8*21.5 + -0.2*44.0 + 1.4*19.0 + -3.0     # = 32.0  -> relu -> 32.0
  z2 = -0.5*21.5 + 0.1*44.0 + 0.3*19.0 + 2.0      # = 1.35  -> relu -> 1.35
  out = 0.6*32.0 + -1.1*1.35 + 0.5                # the output neuron, same recipe
output: |
  hidden = [32.0, 1.35]
  output = 18.21
note: A network is the neuron written out twice, then once more. Nothing else.
narration: |
  Watch it in numbers. The same three inputs go to two hidden neurons, each with its own
  three weights and its own bias. Neuron one: point eight times twenty one point five,
  minus point two times forty four, plus one point four times nineteen, minus three.
  Thirty two. Neuron two: the same recipe with different weights. One point three five.
  Both positive, so relu passes them through unchanged. Then the output neuron takes
  those two hidden values as its inputs, with two more weights and a bias: eighteen
  point two one. A network is the neuron written out twice, then once more. Nothing
  else.
:::

:::scene{type=diagram id=activations}
heading: Activations — and the collapse without one
points:
  - ReLU — max(0, z). Hidden layers, the default
  - Sigmoid — squashes to 0 to 1. A yes-or-no probability
  - Tanh — squashes to −1 to 1. An older hidden-layer choice
  - Without φ — the whole stack collapses to one straight line
narration: |
  The activation functions. Relu: pass positive values, block negative ones; the default
  in hidden layers. Sigmoid: squash any number to between zero and one, for a yes or no
  probability. Tanh: the same squash, to between minus one and one, an older choice for
  hidden layers. Two more you will meet at the output: softmax, which turns several
  scores into probabilities that add to one, and linear, no change at all, for a
  regression output like energy use. And the line at the bottom is the warning: without
  an activation, the whole stack collapses.
:::

:::scene{type=idea icon=warn}
text: Without a nonlinear activation, / any stack of layers is one straight line.
sub: W₂(W₁x) = (W₂W₁)x. Ten linear layers can be replaced by one. Depth only buys you something once φ bends.
narration: |
  This is the most important sentence in the lesson. A layer multiplies by a matrix. Two
  layers in a row multiply by two matrices, which is the same as multiplying by one
  matrix. So without a nonlinear activation, ten layers are exactly one linear model, the
  one that failed in module six. Depth only buys you something once the activation bends.
  Relu bends at zero, and that tiny bend, repeated across hundreds of neurons, is how a
  network draws a curve that no formula wrote.
:::

:::scene{type=diagram id=network}
heading: Layers — input, hidden, output
points:
  - Input layer — building parameters, climate, images, sensors
  - Hidden layers — intermediate representations and interactions
  - Output layer — a number, a class, a field
  - Parameters — one weight per connection, one bias per neuron
narration: |
  Now zoom out. An input layer receives the data: building parameters, climate, images,
  sensor readings. Hidden layers learn intermediate representations, combinations of
  inputs that turn out to be useful. An output layer produces the prediction: a number,
  a class, a whole field of values. Every line in this picture is a weight, and every
  neuron has a bias. When you read a network summary and see a parameter count, this is
  where those parameters live.
:::

:::scene{type=compare}
heading: Shallow or deep?
left:
  title: Shallow — one or two hidden layers
  points:
    - Fewer parameters, faster to train
    - Easier to explain to a reviewer
    - Often all a tabular building problem needs
right:
  title: Deep — several hidden layers
  points:
    - More abstract representations
    - Needs more data, compute, tuning and validation
    - Images, sequences, graphs
verdict: Measured on the 7.4 dataset, identical training — 64-32 reached R² 0.380; 512-256-128-64 reached 0.353. Deeper was not better.
narration: |
  Shallow or deep? A shallow network has one or two hidden layers: fewer parameters,
  faster to train, easier to explain to a reviewer, and often all that a table of
  building data needs. A deep network has several: it can learn more abstract
  representations, at the price of more data, more compute, more tuning and more
  validation. And a measured fact from lesson seven point four: on the same sensor data
  with identical training, a small sixty four by thirty two network scored R squared
  zero point three eight. A network ten times larger scored zero point three five.
  Deeper was not better.
:::

:::scene{type=recap}

  straight line. And deeper is not automatically better. Measure it.
