:::scene{type=title}
narration: |
  Welcome to lesson seven point two, how neural networks learn. Last time you built a
  network by hand and it produced eighteen point two one. Nobody said whether that was
  right. This lesson is about what happens when it is wrong: how the network measures
  how wrong, how it works out which weights are to blame, and how it nudges each one.
  You will do one full update by hand, with numbers small enough to follow.
:::

:::scene{type=diagram id=training_loop}
heading: The training loop
points:
  - Forward pass — predict ŷ from x
  - Loss — how wrong? (ŷ − y)²
  - Backprop — which weights are to blame, and how much
  - Update — w ← w − η · ∂loss/∂w, then repeat
narration: |
  Here is the loop, and everything in deep learning runs inside it. Forward pass: the
  inputs go through the network and come out as a prediction. Loss: compare the
  prediction with the true answer and get one number for how wrong. Backpropagation:
  work out, for every weight, how much it contributed to that wrongness. Update: nudge
  every weight a little in the direction that reduces the loss. Then repeat, thousands of
  times. Steps two to five are one update. One pass over the whole dataset is one epoch.
:::

:::scene{type=compare}
heading: The loss — the one number the network minimises
left:
  title: Mean squared error
  points:
    - (ŷ − y)², averaged
    - Large errors dominate
    - Right when peaks matter, wrong when a few readings are glitches
right:
  title: Mean absolute error
  points:
    - "|ŷ − y|, averaged"
    - Every error counts equally
    - More robust to outliers
verdict: For classification, cross-entropy. For physics-informed learning, a data loss plus an equation loss. The loss is what you tell the network to care about.
narration: |
  The loss is the single number the network tries to make small, so choosing it is
  choosing what the network cares about. Mean squared error squares each gap before
  averaging, so large errors dominate: right when the peaks matter, wrong when a few
  readings are glitches. Mean absolute error counts every gap equally and shrugs at
  outliers. Classification uses cross entropy. Physics informed learning, in module
  eight, adds an equation loss to the data loss. Whatever you choose, the network will
  become exactly as good as that number says, and no better.
:::

:::scene{type=code}
heading: Gradient descent — the whole loop, at its smallest
code: |
  x, target = 2.0, 6.0      # one input, one true answer: y should be 3 * x
  w  = 0.5                  # a random-looking start
  lr = 0.1                  # the learning rate

  for step in range(1, 5):
      prediction = w * x
      loss       = (prediction - target) ** 2
      gradient   = 2 * (prediction - target) * x   # how loss changes if w moves
      w          = w - lr * gradient               # step against it
      print(step, "loss", round(loss, 3), "-> w", round(w, 3))
output: |
  1 loss 25.0 -> w 2.5
  2 loss 1.0 -> w 2.9
  3 loss 0.04 -> w 2.98
  4 loss 0.002 -> w 2.996
note: The target weight was 3.0. Four steps, each one smaller than the last, because the gradient shrinks as the prediction gets close.
narration: |
  Now the loop at its smallest: one weight, one input, one target. The input is two, the
  answer should be six, so the right weight is three. We start at point five. Step one:
  prediction one, loss twenty five, gradient minus twenty, and the weight moves against
  the gradient by a tenth of it, to two point five. Step two: prediction five, loss one,
  weight two point nine. Step three: two point nine eight. Step four: two point nine nine
  six. Each step is smaller than the last, because the gradient shrinks as the prediction
  closes in. That shrinking is what makes the whole thing settle instead of bounce.
:::

:::scene{type=diagram id=loss_landscape}
heading: The learning rate — same bowl, same start, three step sizes
points:
  - Too small — creeps, may never arrive
  - About right — a few steps, straight down
  - Too large — overshoots, and diverges
narration: |
  The learning rate is the size of each step, and it is the first thing to check when
  training misbehaves. Picture the loss as a bowl and the weights as a ball. Too small a
  rate, and the ball creeps and may never reach the bottom. About right, and it gets
  there in a few steps. Too large, and each step overshoots the bottom, lands higher on
  the far side, and the next step is bigger still: the loss diverges. The rule: if the
  loss rises on every step, lower the rate. If it falls but crawls, raise it.
:::

:::scene{type=diagram id=scaling}
heading: Why features are standardised
points:
  - Unscaled — a long narrow valley; many small steps, mostly sideways
  - Standardised — a round bowl; a few steps, straight to the bottom
  - One learning rate is shared by every weight
  - Fit the scaler on the training set only
narration: |
  One learning rate is shared by every weight. If one feature runs from twenty to ninety
  and another from zero to one, the loss surface is a long narrow valley, and a step that
  is right for one direction is wrong for the other: many small steps, mostly sideways.
  Standardise the features, subtract the mean and divide by the spread, and the valley
  becomes a round bowl. A few steps, straight to the bottom. Fit that scaler on the
  training set only; fitting it on everything leaks the test set into training.
:::

:::scene{type=diagram id=backprop_chain}
heading: Backpropagation — the chain rule, in reverse
points:
  - Forward, on top — x becomes z, then a, then ŷ, then the loss L
  - Backward, underneath — how L changes with ŷ, with a, with z, with w
  - Every factor is local — each box only knows its own neighbours
  - One sweep computes every weight's share of the blame
narration: |
  Now the part with the reputation. Forward, along the top: x becomes z, z becomes a, a
  becomes the prediction, the prediction becomes a loss. Backward, underneath: how much
  does the loss change if the prediction moves? If a moves? If z moves? If this weight
  moves? Each of those is a simple local question, and the chain rule says: multiply
  them together. Backpropagation is just the bookkeeping that does this for every weight
  in one sweep, reusing the shared factors. Watch it draw. It is arithmetic, not magic.
:::

:::scene{type=cards}
heading: Words you will see in every training script
items:
  - title: Epoch
    text: One pass over the whole training set.
    tag: how long
  - title: Batch
    text: The rows used for one update. 32 to 256 is common. Cheap, noisy steps that also escape flat regions.
    tag: how many at once
  - title: Optimizer
    text: The update rule. SGD is the plain step; Adam adapts the step per weight and is the default.
    tag: how to step
  - title: Hyperparameter
    text: A setting you choose — layers, neurons, rate, batch, epochs. A parameter is a weight the data chooses.
    tag: yours to set
narration: |
  Four words from every training script. Epoch: one pass over the whole training set.
  Batch: the rows used for one update, commonly thirty two to two hundred and fifty six;
  small batches make cheap, noisy steps, and the noise helps the ball escape flat
  regions. Optimizer: the update rule. Plain gradient descent is the step you just did;
  Adam adapts the step size per weight, and Adam with a rate of one e minus three is the
  default across most problems. And hyperparameter: a setting you choose, as opposed to
  a parameter, a weight the data chooses.
:::

:::scene{type=idea icon=warn}
text: A model does not understand energy. / It learns what the data, the loss and the constraints reward.
sub: If the loss only rewards average accuracy, the model will be bad at peaks and will not tell you. If the features carry no occupancy signal, no amount of training invents one.
narration: |
  And the sentence that carries the responsibility. A model does not understand energy
  automatically. It learns the relationship encouraged by the data, the representation,
  the loss function, and the constraints that the researcher selected. If the loss only
  rewards average accuracy, the model will be bad at peaks and will not tell you. If the
  features carry no occupancy signal, no amount of training invents one. Every one of
  those choices was made by a person. In this course, that person is you.
:::

:::scene{type=recap}
items:
  - Predict, measure the loss, backpropagate the blame, update, repeat
  - The loss is what you tell the network to care about — MSE punishes peaks, MAE shrugs at outliers
  - The learning rate is the step size — too small creeps, too large diverges
  - Standardise features, fitted on training data only
  - Backpropagation is the chain rule, done once for every weight
narration: |
  To remember. Predict, measure the loss, backpropagate the blame, update, repeat. The
  loss is what you tell the network to care about: squared error punishes peaks,
  absolute error shrugs at outliers. The learning rate is the step size; too small
  creeps, too large diverges. Standardise the features, with a scaler fitted on training
  data only. And backpropagation is the chain rule, done once for every weight.
:::
