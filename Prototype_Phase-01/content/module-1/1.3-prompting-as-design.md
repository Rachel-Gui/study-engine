## Architectural Prompt Builder

What happens when design intent becomes language?

Inspect the exact prompt for a small pavilion in a public garden, then change **only its material term**. This controlled generation experiment holds the rest of the prompt and all generation settings fixed. Compare timber, concrete, steel and glass, and rammed earth.

:::genlab{kind=prompt}
title: Architectural Prompt Builder
real_material: true
question: What do you expect from the first example? Before your next test, revise this prediction for the one field you change.
observe: "Did only the material appearance change? Describe a visible difference and one unexpected change."
explanation: "Compare the timber pavilion's planar roof and slender posts with the concrete output's rounded form and broader supports. Material was the only input variable intentionally changed, but several visual/design characteristics changed in response. These differences occurred under controlled generation; this does not establish a mechanistic material explanation for every difference. Prompt terms are not independent parametric design variables."
disclosure: "Mode: Precomputed model outputs — settings shown for reproducibility."
takeaway: Change one prompt field, hold the other settings fixed, and inspect both intended and unexpected effects.
:::

First select the initial example. Then change **Material: Timber → Concrete**, update your prediction, and press **Test one prompt change**. PREVIOUS means your immediately preceding successful example, not a permanently fixed baseline. Changing fields without testing leaves both saved images intact.

The first comparison shows **PREVIOUS — Timber** and **CURRENT — Concrete**. Look for changes in composition, viewpoint and building form as well as material appearance.

:::reflect{feedback="A controlled input change does not isolate a single visual property."}
What does the timber-to-concrete comparison show about changing one prompt term?
- With the seed fixed, material wording should change only surface appearance
- *One changed input can accompany changes in form and openings as well as appearance
:::

:::details{summary="Show reference answer"}
Changing one input term does not isolate one output property. Inspect the roof shape, supports and enclosure as well as apparent material. These are observations about this fixed-seed comparison, not proof that each visual difference has a direct material mechanism. Repeat across several seeds before making broader claims.
:::

## Language is a specification with limits

:::cards
Design intent | Community use and a calm reading environment | State what the proposal should support.
Visual vocabulary | Material, context, lighting and style | Make the intended image legible and comparable.
Performance hint | Passive daylighting or south-facing shading | Suggest an intention that still needs geometry and simulation.
:::

:::keyidea
Prompt terms are not independent parametric variables. A phrase can influence several correlated visual patterns, and wording is not a substitute for explicit constraints.
:::

:::reflect{feedback="Orientation, dimensions and performance still require explicit information and verification."}
A prompt says “south-facing shading.” What has been established by the generated image?
- The depicted overhang is appropriately sized for the stated orientation
- *A possible visual interpretation of the phrase that needs checking
:::

:::details{summary="Show reference answer"}
The image may suggest fins or overhangs. It does not reliably establish north, dimensions, construction or annual performance. Translate the idea into explicit geometry and inputs before evaluating it.
:::

:::details{summary="Design note · Make the brief specific"}
Compare “design a library” with a brief naming a Seattle neighborhood, reading spaces, community use, a site boundary and an area budget. A specific brief is easier to assess, whether drafted by you or an LLM. Check proposed room areas for consistency and fit.
:::
